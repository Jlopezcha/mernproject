# mernproject
Web App similar to social media sites like instagram where the user can log in, post pictures and comment on other users. It is created using the MERN (MongoDB, Express, React, Node) stack .
It uses default data through mongodb but this can be modified by the user (add, update, delete)

to start the code 

make sure you have node js installed then run the commands in the project terminal 

--------------------------------------------
npm install 

node loadDatabase.js 

npm run build 

node webServer.js
